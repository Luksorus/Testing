# Отчет по практической работе: Smoke-чек-лист для интернет-магазина DNS

**Адрес сайта:** https://www.dns-shop.ru/  
**Назначение сайта:** Продажа цифровой и бытовой техники, электроники и сопутствующих товаров с возможностью онлайн-заказа, доставки или самовывоза.  
**Основной пользовательский сценарий:** Пользователь заходит на сайт, находит нужный товар через поиск или каталог, открывает его карточку, добавляет товар в корзину и переходит к началу оформления заказа.

## Цель
Составить чек-лист для быстрой проверки критически важного функционала веб-приложения DNS, чтобы определить пригодность текущей сборки к дальнейшему, более подробному тестированию.

## Smoke-чек-лист

| № | Раздел | Проверка | Статус |
|---|---|---|---|
| 1 | Доступность | Главная страница успешно открывается, базовые элементы интерфейса загружены без ошибок. | 
| 2 | Навигация | Кнопка «Каталог» в шапке сайта открывает выпадающее меню с основными категориями товаров. |
| 3 | Навигация | Иконки «Сравнение», «Избранное» и «Корзина» отображаются в шапке и являются кликабельными. |  
| 4 | Регион | Текущий город отображается в шапке, доступно модальное окно для выбора/изменения региона. |  
| 5 | Поиск | Поиск существующего товара (например, "беспроводная мышь") возвращает релевантные результаты. | 
| 6 | Поиск (ошибочная ситуация) | Поиск несуществующего товара (например, "абракадабра12345") корректно сообщает об отсутствии результатов. |
| 7 | Карточка товара | Карточка выбранного из результатов поиска товара успешно открывается. | 
| 8 | Карточка товара | В карточке отображаются название, актуальная цена, основные характеристики и статус наличия. | 
| 9 | Корзина | Товар успешно добавляется в корзину по нажатию кнопки «В корзину». | 
| 10 | Корзина | В разделе «Корзина» отображается добавленный товар с корректным названием и ценой. | 
| 11 | Корзина | Итоговая сумма в корзине рассчитана корректно (цена товара совпадает с итоговой суммой). | 
| 12 | Корзина | Количество товара в корзине можно изменить (увеличить/уменьшить), при этом сумма пересчитывается. | Pass | 
| 13 | Оформление заказа | Из корзины доступен и корректно открывается первый шаг оформления заказа. |
| 14 | Пустая корзина (ошибочная ситуация) | При переходе в пустую корзину отображается понятное сообщение о её пустоте и предложение добавить товары. |  
| 15 | Отображение | Изображения товаров в каталоге и карточке загружаются корректно, без битых ссылок или плейсхолдеров. |
